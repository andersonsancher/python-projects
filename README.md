# Python Projects

Exercícios e projetos em Python que fiz durante o **Curso Técnico de Informática e Sistemas (Nível 4)** no IEFP. Este repositório mostra a minha evolução desde os fundamentos da linguagem até à programação orientada a objetos.

## Conteúdo

### Fundamentos
Cadernos Jupyter (`.ipynb`) e scripts do início do curso:
- Estrutura de um programa
- Variáveis e tipos de dados
- Operadores e expressões
- `print` e f-strings
- `input` e operações com strings
- Ciclos `for` e `while`
- Ficha de exercícios de consolidação

### `ufcd-0784-funcoes/`: Funções e estruturas de dados
- Parâmetros e argumentos
- `*args` e `**kwargs`
- Âmbito de variáveis (LEGB, `global`, `nonlocal`)
- Recursão
- Funções `lambda`

### `ufcd-0785-poo/`: Programação Orientada a Objetos
- Classes e objetos
- O método `__init__`

## Tecnologias
- Python 3
- Jupyter Notebook
- VS Code

## Como executar
```bash
# Scripts
python nome_do_ficheiro.py

# Cadernos
jupyter notebook
```
